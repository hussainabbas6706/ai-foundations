# AI Foundations

Learning AI/ML fundamentals through implementation — not just theory.

Every concept is coded in Python/NumPy immediately after learning it.
This repo is the mathematical and conceptual foundation for my GenAI and Agentic AI engineering work.

## Structure

- `linear-algebra/` — Vectors, matrices, dot products, eigenvalues implemented in NumPy
- `discrete-structures/` — Logic, graph theory, induction notes and problems
- `prompt-engineering/` — Zero-shot, few-shot, CoT, structured outputs experiments
- `embeddings/` — Semantic similarity, vector search, chunking experiments
- `llm-apis/` — OpenAI API, Google Gemini API

## Stack

Python · NumPy · Jupyter · OpenAI API · Google Gemini API
